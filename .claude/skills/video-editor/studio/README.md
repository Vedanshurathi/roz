# Vedanshu's AI video studio

Read this folder **before every edit** — it is the context that makes edits match Vedanshu's taste.

| folder / file | what goes in it |
|---|---|
| `brand-kit.md` | fonts, colours, caption look, logo/handle rules |
| `editing-style.md` | rules learned from Vedanshu's feedback (what he loved, what he rejected) |
| `references/` + `references.md` | reels he wants to copy, and what each one teaches |
| `raw/` | raw footage for the next edit (big files live in GitHub releases; put a `.txt` with the release URL here) |
| `approved/` | short notes on edits he approved (what made them work) |
| `exports/` | final renders are NOT committed (size); note the delivery date + file name here |

## The loop (every video)
1. Read `brand-kit.md`, `editing-style.md`, `references.md`.
2. Analyse the raw footage: transcribe, find best takes, detect scenes, check light/colour (HDR → tonemap).
3. **Storyboard first:** send a script + a 6–12 frame storyboard grid with timings. Wait for "ok" or feedback.
4. Full render → QC (frames, loudness −14 LUFS, captions in safe zone, re-transcribe final mix) → deliver.
5. **Learn:** append every piece of feedback to `editing-style.md` (date + rule). Never repeat a rejected choice.

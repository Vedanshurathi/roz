# The PROMPT template (for people who comment "PROMPT")

Paste into any AI chat (Claude, ChatGPT, Gemini) and fill the brackets:

```text
Main [kaun ho: student / developer / shop owner…] hoon.
Mujhe [kya chahiye] chahiye, [kiske liye / kise bhejna hai] — kyunki [reason / situation].
Format: [WhatsApp message / email / table / 5 bullet points], [Hinglish / Hindi / English], [kitna lamba: 3 lines / 100 words], tone [polite / friendly / professional].
Ek example jaisa chahiye: [optional: ek sample line ya style].
Pehle mujhse 2–3 sawal pucho agar kuch missing ho, phir answer do.
```

The 3 rules: 1) Context (kaun ho, kise, kyun) 2) Format (kya shape, language, length, tone) 3) AI ko pehle sawal poochne do.
